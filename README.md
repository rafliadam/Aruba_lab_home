# Home Enterprise WiFi Deployment using Aruba AP-207

Description:
Implementation of a WiFi network based on enterprise access points to improve coverage, security, and network segmentation in a home environment, this project using device Aruba HPE AP-207 enterprice.


# Objektif :
1. Membangun jaringan WiFi yang stabil dan aman
2. Memahami konfigurasi access point enterprise
3.Menerapkan konsep dasar networking (SSID, security, DHCP)
4. Melatih troubleshooting pada real environment


# Environment & Tools : 
1. Device Aruba HPE AP-207
2. Router ISP (Indihome)
3. Client: Laptop, Smartphone
4. Network Type: Home Network
